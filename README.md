# Auckland Energy Compare (built site)

Built static site for Auckland energy plan comparison, served by GitHub Pages at https://kiwistyle-24.github.io/auckland-energy-compare-site/

This repo contains **only the generated public build** (HTML, JS, CSS and public plan data in `data/plans.json`).
It holds no personal data: usage is loaded from your own file in your browser and never uploaded.
The source is private. Do not edit files here; they are overwritten on every publish.
